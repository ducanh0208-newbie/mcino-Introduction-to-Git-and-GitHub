# Paradise Nursery Shopping Application

Paradise Nursery is an interactive, user-friendly e-commerce web application built with React and Redux Toolkit for an online plant shop. Users can browse various categories of houseplants, view plant details (images, names, prices, descriptions), add items to their shopping cart, adjust quantities, and calculate total costs dynamically.

## Features
- **Landing Page:** Beautiful full-screen background image with company introduction and a "Get Started" button.
- **Product Listing:** Organized into categories with at least 6 unique plants per category, featuring responsive plant cards and dynamic "Add to Cart" buttons.
- **Redux Shopping Cart:** Global state management using Redux Toolkit (`CartSlice`) to sync item counts across components.
- **Interactive Cart Management:** Dynamically calculate total costs per item and overall cart total, increase/decrease quantities, remove items, and navigate back to shopping.
- **Navigation Bar:** Persistent navbar showing links to Home, Plants, and dynamic total cart count.

## Tech Stack
- React.js
- Redux Toolkit & React-Redux
- CSS3
